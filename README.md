⭐ **Managing Entra ID Users & Role Assignments — Eligible & Active Roles**

📌 **Overview**

🧩** Backstory**

In real IAM environments, managing user roles is critical for:

Least‑privilege access

Compliance

Security governance

Reducing standing admin permissions

To practice these skills, I built a lab environment where I:

Created multiple Entra ID users

Assigned directory roles

Configured eligible role assignments

Activated roles through PIM

Documented the full workflow

This project demonstrates hands‑on identity administration.

⚠️ **The Problem**

Organizations often struggle with:

Too many permanent admin roles

No visibility into who has elevated access

No approval workflow for privileged roles

No auditing of role activation

PIM solves this by requiring users to activate roles only when needed.

**🔧 What This Project Demonstrates**

Creating users in Entra ID

Assigning directory roles

Configuring eligible vs. active assignments

Activating roles through PIM

Reviewing access and role settings

IAM documentation skills
